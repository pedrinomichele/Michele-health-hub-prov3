🔮 Gerar JSON do Google Sheets

✨ MÉTODO SUPER FÁCIL!

Cole um código no Google Sheets e ele gera o JSON automaticamente!

📝 Passo a passo (5 minutos):

1. Organize seus dados no Google Sheets com estas colunas:
Data | Peso | Sono | Humor | BB | Estresse | Treino | Kcal Treino | GET | Consumido | Prot | Carb | Gord | Fase | Mind

2. No Google Sheets, vá em: Extensões → Apps Script

3. Clique no botão abaixo para copiar o código

4. Cole o código no Apps Script e salve (Ctrl+S)

5. Clique em ▶️ Executar (função exportToJSON)

6. Autorize quando pedir permissões

7. Vai gerar um arquivo "michele-health.json" no seu Google Drive!

8. Baixe o arquivo do Drive

9. Clique em "📤 Importar JSON" aqui e selecione o arquivo

PRONTO! 🎉 Todos os dados importados!
💡 Dica: Depois de gerar o JSON uma vez, você pode usar o mesmo arquivo sempre! Atualize os dados no Sheets e execute novamente para gerar um novo JSON.

📊 Google Sheets - Sincronização

📝 Passo a passo:

1. Crie uma planilha no Google Sheets
2. Vá em Extensões → Apps Script
3. Clique em "📋 Copiar Código" abaixo e cole no Apps Script
4. Clique em 💾 Salvar (ícone de disquete)
5. Clique em ▶️ Executar (autorize as permissões)
6. Clique em 🚀 Implantar → Nova implantação
7. Tipo: Aplicativo da Web
8. Execute como: Eu | Acesso: Qualquer pessoa
9. Copie a URL gerada e cole abaixo
10. Clique em "🔄 Sincronizar Agora"

⚠️ A URL deve terminar com /exec (não /dev)
