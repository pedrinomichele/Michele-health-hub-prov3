# 💜 Michele Health Hub Pro  

Meu painel pessoal pra organizar a vida, o caos e o glow.  
Aqui eu acompanho peso, humor, ciclo, treinos, estresse, sono, alimentação e o que mais fizer sentido no meu autocuidado.

Eu não comecei sabendo nada disso aqui. Mas quando comecei, achei tão fantástico, que não parei até conseguir. 
E esse projeto virou uma das coisas que mais me orgulho de ter criado.

---

## ✨ O que esse hub faz

- KPIs diários (calorias, macros, treino, déficit)
- Gráficos lindos com Chart.js
- Análise por fase do ciclo (com insights automáticos)
- Histórico editável e ordenável
- Projeção de peso baseada em déficit e tendência real
- Dashboard 100% responsivo
- Importar/Exportar JSON
- Integração com Google Sheets pra deixar tudo organizado
- Funciona offline (LocalStorage, meu bem)
